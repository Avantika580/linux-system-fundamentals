# Linux System Fundamentals

A hands-on Linux learning repository covering Bash scripting, C programming with GCC, and Linux log analysis and troubleshooting.

## Environment

- OS: Ubuntu 24.04.5 LTS
- Compiler: GCC 13.3.0
- Platform: Ubuntu running inside Docker Desktop

## Topics Covered

### 1. Bash Scripting
- Variables and command substitution
- Conditional statements (if-else)
- File and directory checks
- User input using read
- Exit statuses and error handling

Folder: `bash-scripting/`

### 2. C Programming and GCC
- Writing and executing C programs
- Compiling programs using GCC
- Understanding preprocessing, compilation, assembly, and linking

Folder: `c-gcc/`

### 3. Linux Logs and Troubleshooting
- Inspecting application logs
- Searching errors and warnings using grep
- Filtering and counting log entries
- Using pipes to combine commands
- Monitoring logs in real time using tail -f

Folder: `logs-troubleshooting/`

## Repository Structure

## Purpose

This repository documents practical Linux fundamentals through hands-on exercises and command-line practice.
